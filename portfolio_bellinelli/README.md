# Portfólio de Bellinelli

## Como abrir
1. Extraia a pasta `portfolio_bellinelli`.
2. Abra `index.html` em um navegador.
3. Para editar, abra a pasta em um editor como VS Code.

## Estrutura
- `index.html`: conteúdo e estrutura semântica.
- `css/style.css`: cores, layout e responsividade.
- `js/script.js`: menu, saudação, tema, validação, ano e filtro de projetos.
- `img/`: reservado para imagens próprias, se desejar adicionar uma.

## Personalizações importantes
- Confira o texto da seção "Sobre mim".
- Confirme se os três projetos descritos correspondem aos trabalhos que você realmente concluiu.
- Ajuste os níveis de habilidades para refletir sua experiência real.
- Adicione links reais de GitHub/LinkedIn e repositórios, se tiver.
- O formulário é demonstrativo: ele não envia nem armazena dados.
- O código inclui comentários didáticos; leia-os e teste as mudanças.

## Testes recomendados
- Redimensione o navegador para 360 px, 768 px e 1280 px.
- Teste o menu hambúrguer, tema claro/escuro, filtros e formulário.
- Navegue com Tab e Shift+Tab.
- Abra o console do navegador e confira se há erros.

## Uso de IA
O cabeçalho do `js/script.js` declara que o ChatGPT foi usado para gerar uma primeira versão do código e apoiar explicações, organização e revisão. Mantenha a declaração fiel ao processo real e revise o projeto antes de entregá-lo.
